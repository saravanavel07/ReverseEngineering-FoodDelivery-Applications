> **OrangeBite** is an end-to-end, production-style Indian food delivery platform inspired by observable architectural patterns of modern Indian platforms, built with original branding, independently designed interfaces, and documented engineering decisions.

## 🍊 Project Objectives & Methodology

OrangeBite demonstrates clean-room software reverse engineering through authorized reconnaissance, behavioral decomposition, and independent implementation.

<table>
<tr>
<td width="50%">

**🔎 1. Authorized Reconnaissance**

Observes public state transitions, cart constraints, and user journeys without accessing proprietary code or private endpoints.

</td>
<td width="50%">

**⚙️ 2. Behavioral Reconstruction**

Implements authoritative server-side business rules where the client never dictates final monetary totals.

</td>
</tr>
<tr>
<td width="50%">

**🏗️ 3. Independent Implementation**

Clean Django models, atomic database transactions, DRF serializers, and custom UI design tokens.

</td>
<td width="50%">

**🛡️ 4. Safety & Boundaries**

Development payment simulation never stores or requests sensitive card numbers, CVVs, or UPI PINs.

</td>
</tr>
</table>

## 🚀 Quickstart & Local Development

<details open>
<summary><b>1. Create a virtual environment and install dependencies</b></summary>

```bash
python3 -m venv .venv
source .venv/bin/activate
# Windows: .venv\Scripts\Activate.ps1
pip install -r requirements/development.txt
```

</details>

<details>
<summary><b>2. Apply migrations and seed demo data</b></summary>

```bash
python manage.py migrate
python scripts/seed_demo_data.py
```

</details>

<details>
<summary><b>3. Run the automated test suite</b></summary>

```bash
pytest
```

</details>

<details>
<summary><b>4. Start the development server</b></summary>

```bash
python manage.py runserver
```

Open `http://localhost:8000` (or `http://localhost:3000` in AI Studio).

</details>

## 🐳 Docker Deployment

Launch the production-style PostgreSQL, Redis, and Gunicorn stack:

```bash
docker-compose up --build
```

Open `http://localhost:8000`, or `http://localhost:3000` when running in AI Studio.

## 🔐 Security & Privacy Notice

- **Payment Safety:** All payments run in simulated test mode. No money is charged, and no card numbers, CVVs, or UPI PINs are processed.
- **Original IP:** OrangeBite uses original names, logos, color codes, and assets. It does not reproduce proprietary logos or private source code.
